# Provider Policy Sources

Last verified: 2026-05-31

This file pins the source URLs and operational decisions that must be re-checked before any live LLM call. It does not replace legal review.

## P0b decision

For v1, the product may scaffold provider configuration, but it must not send live student data until a specific provider, account setting, and retention mode are recorded here.

Current default decision:
- Runtime provider: Anthropic Messages API or OpenAI API through server-side API keys only.
- Browser access: no direct API-key exposure; all calls go through the backend.
- Student data: opaque `student_id`; no real names in prompt context; redaction before logs.
- Under-13: out of scope for v1.
- Ages 13-17: require age-appropriate disclosures, content filtering, monitoring/escalation, and parent-created account flow before live LLM use.

## Source pins

OpenAI data controls:
- URL: https://platform.openai.com/docs/guides/your-data
- Last verified: 2026-05-31
- Current relevant facts: API data is not used to train or improve OpenAI models unless explicitly opted in. Abuse monitoring logs are generated by default and retained for up to 30 days unless legally required longer. Zero Data Retention and Modified Abuse Monitoring are configurable after approval.

OpenAI under-18 API guidance:
- URL: https://platform.openai.com/docs/guides/safety-checks/under-18-api-guidance
- Last verified: 2026-05-31
- Current relevant facts: products serving minors need additional safeguards. The guidance calls out age-appropriate disclosures, content filters, monitoring/reporting/escalation paths, and age assurance where appropriate. It says not to process personal data of children under 13 or the applicable age of digital consent without Zero Data Retention.

Anthropic API data retention:
- URL: https://platform.claude.com/docs/en/manage-claude/api-and-data-retention
- Last verified: 2026-05-31
- Current relevant facts: Anthropic documents Zero Data Retention for eligible API usage. Messages API and token counting are ZDR eligible under the documented arrangement. Some features are not ZDR eligible, and policy-violation/legal exceptions may allow retention.

Desmos terms:
- URL: https://www.desmos.com/terms
- Last verified: 2026-05-31
- Current relevant facts: Desmos Tools are not approved for commercial embedding without terms review and written commercial permission. The v1 graph path must work through a local fallback without Desmos.

## P6 re-check

Before enabling live model calls:
- Re-open every source URL above and update the date/facts here.
- Record the exact provider, org/project settings, retention mode, and disabled ineligible features.
- Confirm the account has the required Zero Data Retention or equivalent setting if any protected minor data could be processed.
- Confirm the deployed prompt includes the child-safety rules from `docs/llm-contract.md`.
- Confirm logs do not contain raw student text, real names, API prompts, or model responses unless explicitly allowed by the retention decision.
